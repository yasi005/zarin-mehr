# Zarrin Mehr

A bilingual experience game for **Zarrin Mehr** — the seasonal benefits program of **Zarrin Group (گروه زرین)** in Iran.

Players choose 15 experiences across joy, learning, and wellness. Their mix shapes a light-inspired personality result — and enters them into the seasonal Zarrin Mehr draw.

---

### About Zarrin Mehr

Zarrin Group is one of Iran’s well-known industrial and consumer brands. **Zarrin Mehr** is its seasonal care program for people in the Zarrin family — an invitation to spend benefits on real experiences, not a fixed list of activities. This project turns that idea into a calm, playful web journey: choose what fits you, see what your choices say, and take part with elegance.

---

### Features

- Persian & English (RTL / LTR)
- Home story, login, experience selection, and result screens
- Responsive layout for phone and desktop
- Local time + language switch in the header
- Personality results mapped to light metaphors

### Stack

React · Vite · styled-components · Framer Motion · Swiper · Sass

---

### Getting started

```bash
npm install
npm run dev
```

Optional API base URL (defaults to `http://localhost:5000`):

```bash
# .env.development
VITE_API_BASE=http://localhost:5000
```

```bash
npm run build
npm run preview
```

### Project note

This repository contains the **frontend**. Connect it to your own backend for authentication, verification, and score saving. Do not commit secrets, credentials, or private employee data.
